# Referências confirmadas dos projetos

## Casamento em Ordem

O repositório de documentação oficial é [CasamentoemOrdem-README](https://github.com/IversonSantos-dev/CasamentoemOrdem-README). O README apresenta a solução como uma plataforma de planejamento de casamentos desenvolvida com React, TypeScript e Tailwind CSS, com gerenciamento de convidados, presentes, finanças e site personalizado. Ele também aponta para o [site de produção](https://casamentoemordem.com.br/) e para o [repositório de código-fonte](https://github.com/IversonSantos-dev/casamentokrisiciaiverson).

## Fintrack

O repositório [fintrack-digital-home](https://github.com/IversonSantos-dev/fintrack-digital-home) está disponível publicamente. Sua estrutura inclui `src`, `supabase`, Vite, TypeScript, Tailwind CSS, Bun e componentes de interface; a página de linguagem do GitHub indica predominância de TypeScript e presença de PL/pgSQL. O README aponta para um projeto Lovable, mas não publica uma URL de demonstração independente.
